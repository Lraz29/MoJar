# MoJar 💰📈
MoJar is a collaborative financial management Android application designed to help households track expenses, set savings goals, and visualize their financial health in real-time.

## ✨ Features
* **Shared Households:** Join or create a "Jar" with a unique code to sync data with family or roommates.
* **Real-time Sync:** Powered by Firebase Firestore – see updates instantly across all devices.
* **Visual Analytics:**
    * **Pie Charts:** Monthly expense breakdown by category.
    * **Bar Charts:** Income vs. Expense comparisons.
    * **Line Charts:** Cumulative growth and spending trends.
* **Smart Spending Mood:** An algorithm that calculates your "financial mood" based on your savings ratio.
* **Savings Goals:** Set long-term targets and track your progress with a dynamic donut chart.

## 🛠 Tech Stack
* **Language:** [Kotlin](https://kotlinlang.org/)
* **Database & Auth:** [Firebase](https://firebase.google.com/) (Firestore & Google Sign-In)
* **Charts:** [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart)
* **Animations:** [LottieFiles](https://lottiefiles.com/)
* **UI:** ViewBinding, Material Design, RecyclerViews.


## 🚀 Getting Started
1. Clone the repository.
2. Add your `google-services.json` to the `/app` folder.
3. Build and run on an Android device or emulator.
